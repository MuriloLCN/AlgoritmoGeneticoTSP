# Algoritmo Genético TSP

Este projeto foi feito como trabalho das disciplinas de Modelagem e Otimização de Algoritmos e também Programação Concorrente. Nele, foram implementadas diversas heurísticas e meta-heurísticas para a resolução do problema do caixeiro viajante com instâncias do problema advindas da TSPLIB.

No branch principal, há a versão sequencial do código. Além disso, nas demais branches, há três versões paralelizadas:

* Paralelização com MPI
* Paralelização com threads normal
* Paralelização com threads utilizando master-worker

Uma documentação mais expansiva de todo o processo seguido bem como os resultados obtidos estão dispostos nos PDFs presentes no repositório ([Relatório MOA](Avaliação_3___MOA.pdf), [Relatório PC](Relatório_PC.pdf)). OBS: Os relatórios são relativamente grandes e podem não carregar no visualizador de PDFs do GitHub.
